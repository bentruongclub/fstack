# ship

1. Name what lands. One commit's worth. Not a manifesto.
2. Read the diff. Drop secrets and noise.
3. Prove it first (`principles/prove-it.md`). No evidence, no ship.
4. Commit locally. Short why-message.
5. Push only if a remote exists. If none, stop and say so. Do not invent a remote.
6. Done when: a commit hash on disk, and either a remote tip that matches or an explicit "local only, no remote".
