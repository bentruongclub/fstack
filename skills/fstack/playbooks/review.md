# review

1. Name what is under review: path, commit, or diff. One sentence.
2. Read the actual artifact. No summary-of-intent review.
3. Verdict in three lines max: ship / hold / fix. One concrete reason each time you hold or fix.
4. Hold or fix must name the file or command that proves the gap.
5. Do not rewrite the change in this playbook. Hand rewrite to fix or open-file. Hand land to ship.
