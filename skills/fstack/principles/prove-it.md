# Prove it

Done means a real artifact. Not a vibe. Not "looks right".

## When

After the playbook's work. Before you say it landed.

## What counts

- A file on disk you can open.
- A command's output, not a paraphrase of what you hoped it would print.
- A PR URL that exists.
- A failing repro that now fails to fail.

## What does not

- A plan.
- A summary of intent.
- "Should work".
- Tests you did not run.

## Do

1. Name the artifact.
2. Produce or open it.
3. Quote the evidence (path, output, URL).
4. If you cannot, it is not done. Keep working or say what is missing.

One principle. Not a catalog.
