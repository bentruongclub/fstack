# One job

One outcome. One file or one playbook. Not a platform rewrite.

## When

Before you expand the ask. When a second job shows up mid-run.

## What counts

- A named outcome you can finish in this turn or this commit.
- The NEXT.md head, if the ask is "ship the pack".
- One playbook from the route table.

## What does not

- A second skill "while you're in there".
- Renaming the product mid-file.
- Remote auth theater when the open file does not need a remote.
- A manifesto, ethos doc, or skill catalog as a substitute for the open file.

## Do

1. Name the one job in a short sentence.
2. Open the matching playbook. Run its steps.
3. Park anything else in `PARKED.md`. Do not start it.
4. Done when that one job has a real artifact (`principles/prove-it.md`).

One principle. Not a catalog.
